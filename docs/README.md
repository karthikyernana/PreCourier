# PreCourier Documentation

`PRD.md` is the complete and canonical product requirements document. This directory adds implementation evidence, scope sequencing, architecture, contracts, India-market constraints, testing requirements, and future-agent instructions. It does not replace or summarize away any PRD requirement.

## Start here

1. `CURRENT-STATE.md`: what the repository actually implements.
2. `MVP.md`: the current India-first build and release gate.
3. `POST-MVP.md`: the remaining features and their dependencies.
4. `ARCHITECTURE.md`: current and target system boundaries.
5. `API-CONTRACTS.md`: current and target request semantics.
6. `INDIA-READINESS.md`: launch assumptions and blockers for Indian B2B customers.
7. `ROADMAP.md`: phase-by-phase implementation status.
8. `TEST-MATRIX.md`: existing evidence and missing tests.
9. `HANDOFF.md`: the next safe task for a future AI agent.

## Status legend

- **Implemented**: source exists and the relevant behavior is tested.
- **Partial**: a foundation exists but the PRD behavior is incomplete.
- **Specified**: described by the PRD but not present in runtime source.
- **Planned**: assigned to a future phase.
- **Blocked**: dependent on an external provider, legal decision, or unresolved contract.
- **Post-MVP**: deliberately not in the current release gate.
- **Non-goal**: explicitly excluded by the PRD.
